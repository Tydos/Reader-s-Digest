## How it works

1. **Discover** — `scripts/fetch_articles.py` pulls trending stories from
   [Hacker News](https://news.ycombinator.com/) (Algolia API) and runs
   site-restricted web searches across quality publications in
   [`config/sources.txt`](config/sources.txt).
2. **Filter** — Articles are deduped by URL and matched to your interests in
   [`config/interests.yaml`](config/interests.yaml).
3. **Publish** — `scripts/generate_pages.py` updates this README table and the
   interactive card view at [`docs/index.html`](docs/index.html).

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python scripts/update.py
```

Regenerate pages without fetching:

```bash
python scripts/update.py --skip-fetch
```

Preview the interactive digest locally:

```bash
python -m http.server 8000 --directory docs
# open http://localhost:8000
```

## Customize your feed

Edit [`config/interests.yaml`](config/interests.yaml) to change topics, time range,
and Hacker News score threshold. Add or remove publication domains in
[`config/sources.txt`](config/sources.txt).

## Automation

GitHub Actions (`.github/workflows/update-articles.yml`) runs daily at 08:00 UTC
and on manual dispatch. It fetches articles, regenerates this README + `docs/`,
and commits when anything changed.
